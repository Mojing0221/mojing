鍊金工房 (專案代號)

結合資源管理與魔法陣經營的 2D 模擬遊戲

專案概述

這是一款以鍊金術為主題的模擬經營遊戲。玩家將扮演見習鍊金術士，透過收集素材、調和藥劑與解鎖魔法陣來推進劇情。我在本作中主要負責核心系統的程式邏輯與部分視覺特效的 Shader 撰寫。

  • 開發引擎： Unity (URP)
  • 擔任職務： 程式設計、技術美術 (TA)
  • 開發時長： 2025.12 - 至今
  • 使用技術： C#, Shader Graph, DOTween

技術實作亮點

1. 魔法陣與寶石的 URP 流光特效

為了強化魔法陣啟動時的視覺回饋，我使用 Shader Graph 撰寫了專屬的材質渲染。透過控制 UV 偏移與 Emission 節點，實現了魔法陣線條上的流光感覺以及物件寶石的光澤感。

2. JSON 動態資源管理系統

為了方便後續企劃調整數值，我實作了一套基於 JSON 的資源管理系統 (resource.json)。能動態處理遊戲內貨幣（如：1 顆鑽石轉換成 24 枚金幣）與體力的消耗計算。

3. 沉浸式液體溶解轉場與 DOTween 動畫

捨棄傳統的黑屏 Loading，我利用 `Mat_AlchemyDissolve` 材質球製作了客製化的液體溶解轉場效果來切換場景。同時搭配 DOTween 處理 UI 頁面從左側滑入至畫面中間的緩動動畫，提升整體遊戲打擊感與流暢度。
